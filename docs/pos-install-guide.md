# 포스 설치 가이드 (영수증리뷰 에이전트)

> 대상: 광고토대왕 직원(원격 지원) / 점주(자가 설치)
> 최신 버전·다운로드: https://placemaster.co.kr/receipt-review.html → 가입·로그인 → [다운로드]
> (직접 주소: https://review.placemaster.co.kr/download/latest)

---

## 1. 준비물

| 항목 | 내용 |
|---|---|
| 포스 OS | Windows 7 SP1 이상 (32·64비트 모두 가능), Windows 10/11 권장 |
| .NET | .NET Framework 4.6.2 이상 (윈도우 10 이상은 기본 포함) |
| 프린터 | 시리얼(COM)·USB-시리얼 프린터, **윈도우에 등록된 프린터(랜선·와이파이·USB 드라이버)** 모두 자동 감지 |
| 계정 | 사이트에서 가입 → 운영자 승인된 점주 이메일·비밀번호 |
| 권한 | 처음 설치할 때 1번만 관리자 권한 필요 |

> 랜선·와이파이 프린터는 포스가 **윈도우 프린터로 인쇄하는 경우** 자동 감지됩니다 (v1.1.3~).
> 포스 프로그램이 프린터 IP로 직접 보내는 경우, 그리고 안드로이드 태블릿 포스(토스포스 등)는 지원하지 않습니다.

## 2. 설치 순서

### zip 으로 받은 경우 (현재 배포 방식)
1. `ReceiptTap_v1.x.x.zip` 을 **`C:\ReceiptTap`** 폴더에 압축 풀기
   - 바탕화면·다운로드 폴더도 되지만, 지우기 쉬운 곳은 피하세요
2. `install.bat` 우클릭 → **관리자 권한으로 실행**
   - 카솔이 설치된 포스는 SPMC가 이미 있어서 "건너뜀"으로 나옵니다 (정상)
3. `ReceiptTap.exe` 실행 → 로그인 창에 점주 이메일·비밀번호 입력
4. 작업표시줄 오른쪽 아래 **초록색 N 아이콘** 확인
5. **포스에서 영수증 1장 출력** → "프린터 자동 연결됨" 알림이 뜨면 완료

### Setup.exe 로 받은 경우 (정식 설치 파일)
1. `ReceiptTap_Setup_1.x.x.exe` 실행 → [예] (관리자 권한) → 다음 → 설치
2. 설치가 끝나면 자동 실행 → 로그인
3. 포스에서 영수증 1장 출력 → 자동 연결 확인
- 설치 폴더: `C:\Program Files\ReceiptTap`, 모든 사용자 로그인 시 자동 실행

---

## 3. 설치 후 확인 (상태판)

작업표시줄 N 아이콘을 누르면 상태판이 열립니다.

| 항목 | 정상 |
|---|---|
| 상단 상태 | **정상 작동 중** (초록 점) |
| 프린터 포트 | COM 번호 + "(자동 연결됨)" |
| 서버 연결 | 정상 (마지막 확인 시각) |
| 오른쪽 | 방금 출력한 영수증 내용 + "서버: 서버 전송 완료" |

N 아이콘 오른쪽 아래 점 색:
- 초록 = 정상 / 파랑 = 프린터 찾는 중(영수증 1장 출력 필요) / 노랑 = 서버 연결 안 됨(인터넷 확인, 영수증은 보관 후 자동 재전송) / 빨강 = 영수증 읽기 오류 또는 다시 로그인 필요

### [테스트 확인] 버튼
누르고 90초 안에 포스에서 영수증을 출력 → 읽어온 내용이 오른쪽에 표시되면 성공.

### 프린터를 직접 지정해야 할 때
자동 연결이 엉뚱한 포트를 잡는 경우만: 상태판 → "직접 선택" → 포트 고르기 → [적용] → 영수증 1장 출력으로 확인.

---

## 4. 가장 중요한 확인: 영수증 출력이 평소와 같은지

에이전트는 프린터로 가는 데이터를 **옆에서 읽기만** 합니다 (카솔과 같은 방식). 설치 후 반드시:
1. 결제 영수증이 평소처럼 나오는지
2. 에이전트를 종료(N 아이콘 → 종료)해도 영수증이 나오는지

둘 중 하나라도 이상하면 즉시 에이전트 종료 후 담당자에게 연락.

## 5. 백신이 막을 때 (V3, 알약 등)

서명되지 않은 프로그램이라 처음에 경고가 나올 수 있습니다 (판매 전 코드 서명 예정, D7).

| 증상 | 조치 |
|---|---|
| "Windows의 PC 보호" 파란 창 | [추가 정보] → [실행] |
| V3 / 알약이 ReceiptTap.exe 를 격리 | 백신 → 검역소(격리함)에서 복원 → **예외(허용) 목록**에 설치 폴더 추가 (`C:\ReceiptTap` 또는 `C:\Program Files\ReceiptTap`) |
| install.bat 실행 직후 창이 바로 닫힘 | 관리자 권한으로 실행했는지 확인. 백신 실시간 감시를 잠시 끄고 다시 실행 |
| 자동 업데이트 후 프로그램이 안 켜짐 | 백신 검역소 확인 → 복원·예외 추가 → `ReceiptTap.exe` 다시 실행 |

## 6. 자동 업데이트

- 프로그램이 켜진 뒤 30초, 이후 6시간마다 새 버전을 확인합니다.
- 새 버전이 있으면 몇 초 동안 프로그램이 꺼졌다 켜집니다 (점주 조작 불필요, 출력에는 영향 없음).
- **1.1.0 이하 버전은 자동 업데이트가 되지 않습니다** → 새 버전을 받아 다시 설치하세요.

## 7. 문제 해결

| 증상 | 확인 |
|---|---|
| "프린터 찾는 중"에서 안 바뀜 | 영수증을 1장 출력했는지 확인. 그래도 안 되면 로그 확인: "형식 인쇄는 읽지 않음"이 보이면 포스가 그림(드라이버) 방식으로 인쇄 중 → 담당자 문의. 아무 기록이 없으면 포스가 프린터 IP로 직접 전송하는 방식(미지원) |
| "영수증 읽기 오류" | SPMC 설치 안 됨 → `install.bat` 관리자 권한으로 다시 실행 |
| "다시 로그인 필요" | N 아이콘 클릭 → 로그인 |
| "서버 연결 안 됨" | 인터넷 확인. 영수증은 최대 48시간 보관 후 자동 재전송 |
| "이미 실행 중입니다" | 이미 켜져 있음. N 아이콘을 누르세요 |

로그 위치: `C:\ProgramData\ReceiptTap\logs\` (날짜별, 7일 보관) — 상태판 [로그 보기]로 열 수 있습니다.
문제가 있으면 오늘 날짜 로그 파일을 담당자에게 보내주세요.

## 8. 제거

- Setup.exe 로 설치: 제어판 → 프로그램 제거 → 영수증리뷰
- zip 으로 설치: N 아이콘 → 종료 → 폴더 삭제
- SPMC(카솔과 공용 부품)는 제거하지 않습니다. 카솔이 계속 사용합니다.
